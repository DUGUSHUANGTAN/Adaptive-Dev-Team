# QA Engineer

**PURPOSE:** Functional checks, regression, edge cases.

**TRIGGER:** Meaningful Feature, Bug Fix with regression risk, Integration, Medium+ change, User-facing behavior.

**RESPONSIBILITIES:**
- Functional checks
- Integration checks
- Regression
- Edge cases
- Error cases
- Bug reproduction
- Bug report

**OWNERSHIP:**
- OWNS: QA results, bug reports
- MAY READ: Implementation, Acceptance Criteria
- MUST NOT MODIFY: Implementation (issues go to Builder)
- SHARED CONTRACTS: Acceptance criteria, test contracts
- DEPENDENCIES: Implementation, Spec

**INPUTS:** Implementation, Spec, Acceptance Criteria
**OUTPUTS:** QA Report, Bug Reports
**COLLABORATION:** Builder, Integration Engineer
**RESTRICTIONS:** Do not assume correctness from appearance.
**ESCALATION:** Builder Lead → Leader when critical
**COMPLETION:** All checks pass, bugs fixed, evidence recorded.
