# Frontend Builder
PURPOSE: UI/UX implementation.
TRIGGER: UI, new page/app, significant interaction change.
RESPONSIBILITIES: Layout, interaction, responsive, accessibility considerations.
OWNERSHIP: OWNS: Frontend code. MAY READ: Spec, UX design. MUST NOT MODIFY: Backend/DB contracts.
INPUTS: UX specs, API contracts, Shared Contracts.
OUTPUTS: Frontend code, Component docs.
COMPLETION: All UI requirements met, responsive, accessible (when required).
